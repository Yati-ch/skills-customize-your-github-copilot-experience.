# 📘 Assignment: Building Interactive Web Pages with HTML, CSS & JavaScript

## 🎯 Objective

Learn to create dynamic, interactive web pages by combining HTML for structure, CSS for styling, and JavaScript for interactivity. You'll build a personal portfolio page that showcases your skills and allows users to interact with it.

## 📝 Tasks

### 🛠️ Build a Personal Portfolio Page

#### Description
Create an interactive personal portfolio website that displays your information, projects, and skills. The page should have a clean, professional design with proper HTML semantics, responsive styling, and interactive navigation.

#### Requirements
Completed program should:

- Have a semantic HTML structure with header, navigation, sections for projects/skills/about, and footer
- Include at least 3 projects with descriptions and links
- Use CSS for styling with a consistent color scheme and professional layout
- Implement responsive design that works on mobile, tablet, and desktop
- Include at least one image or icon
- Be styled with CSS Grid or Flexbox for layout

### 🛠️ Add Interactive Features with JavaScript

#### Description
Enhance your portfolio with JavaScript interactivity. Add features that make the page engaging, such as smooth navigation, form validation, interactive elements, or dynamic content updates when users interact with the page.

#### Requirements
Completed program should:

- Have a working navigation menu (smooth scrolling or active section highlighting)
- Include at least one interactive element (button with hover effects, toggle, or modal)
- Implement form validation if a contact form is included
- Use DOM manipulation to add/remove or update page content
- Have event listeners for user interactions (click, hover, scroll)
- Include proper error handling for edge cases
